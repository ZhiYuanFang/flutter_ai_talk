# 键盘顶部输入确认条回退策略

适用变更：`keyboard-top-input-confirm-bar`

## 回退目标

当线上出现严重输入异常（无法提交、焦点错乱、页面误关闭）时，快速恢复旧输入行为。

## 回退顺序

1. **全局回退（最快）**
   - 在 `app/lib/app.dart` 暂时移除 `KeyboardInputConfirmBarOverlay`。
   - 保留页面原有输入控件与提交按钮路径。

2. **页面级回退（按影响面）**
   - 优先回退登录/注册/首页：
     - 取消字段对 `keyboardInputBridgeController` 的 `attach/updateDraft` 调用。
     - 保留原 `onSubmitted` 与按钮点击提交逻辑。

3. **弹层级回退**
   - 回退设置弹窗、历史编辑、数值备注中的桥接接入。
   - 保留原弹窗按钮确认与保存按钮逻辑。

## 回退后验证清单

- 登录/注册是否可通过原按钮完成提交。
- 首页文本输入是否可通过原提交按钮完成命令发送。
- 设置弹窗和历史备注是否仍可正常保存。
- 点击空白收键盘行为是否正常。

## 风险提示

- 若仅回退局部页面，可能出现新旧输入交互并存；建议按“全局 -> 页面 -> 弹层”的顺序执行，保证行为一致性。
