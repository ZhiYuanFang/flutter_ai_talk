# refactor-trends-center-ui 设计

## Context

当前趋势中心由 `TrendsScreen` 提供页面骨架，采用「AppBar + 顶部双胶囊 + 图表玻璃区」结构。事件选择与日期范围选择入口位于图表外层顶部，图表内部仅展示标题与坐标说明文本。该结构带来三个问题：

1. 视觉焦点分散：用户查看图表时需要回到顶部控件区进行切换。
2. 结构冗余：图表头部已有标题，顶部又存在独立筛选区，层级重复。
3. 沉浸感不足：AppBar 与控件条占据可视高度，不利于趋势图主视图表达。

现有能力中，事件选择（含记忆）、日期范围选择（含记忆）、序列加载与登录遮罩均已稳定；本次重构必须复用这些能力，不改动数据契约。

## Goals / Non-Goals

**Goals:**

- 将趋势中心改为“图表主视图优先”的布局，移除 AppBar 与顶部双胶囊筛选区。
- 在图表头部统一承载交互：logo、可点击标题（事件选择）、可点击日期范围（范围选择）。
- 标题右侧展示下拉箭头，明确当前趋势图可切换事件。
- 去除纵轴语义说明文案，减少重复文本噪声。
- 保持既有事件记忆、日期范围记忆、序列请求与登录遮罩行为不变。

**Non-Goals:**

- 不修改趋势接口、事件目录接口、`TrendSeries` 数据结构。
- 不改动事件选择 Sheet 与日期选择 Sheet 的核心交互流程。
- 不更改图表分桶策略（单日小时、多日按天）与坐标抽稀算法。
- 不在本次变更中引入新的全局状态管理方案。

## Decisions

1. **页面骨架改为无 AppBar 的沉浸式布局**
   - 决策：`TrendsScreen` 移除 `AppBar`，保留主体内容区并扩展图表区域高度。
   - 原因：满足“背景近全屏”目标，避免顶部栏占高。
   - 备选：保留极简 AppBar。未采纳，仍会割裂图表视觉。

2. **交互入口收敛到图表头部**
   - 决策：将事件选择与日期范围选择入口从顶部胶囊迁移至 `TrendGlassBarChart` 头部，分别通过回调触发现有 `_openEventPicker()` 与 `_openDateRangePicker()`。
   - 原因：复用既有弹层与状态流，降低回归风险。
   - 备选：新增独立头部组件并复制逻辑。未采纳，易产生状态分叉。

3. **头部信息层级固定为 logo → 标题（可点）→ 日期范围（可点）**
   - 决策：标题行右侧强制显示 `expand_more`，体现可选事件；日期范围显示在标题下方并可点击打开日期 Sheet。
   - 原因：满足用户感知与交互一致性。
   - 备选：仅在有多个事件时显示箭头。未采纳，弱化可发现性。

4. **移除纵轴语义说明文案，保留图表坐标表达**
   - 决策：删除图表顶部“纵轴含义”文本，不再额外解释“小时/次数”。
   - 原因：减少视觉负担，避免重复表达。
   - 备选：改为 tooltip 说明。未采纳，本次需求明确不展示该含义文案。

5. **状态与加载时序保持现状，不引入新存储键**
   - 决策：事件与日期范围仍使用既有 store；仅迁移入口位置，不改变保存/恢复语义。
   - 原因：最小变更策略，确保功能连续性。
   - 备选：新增“图表头部状态”持久化。未采纳，无必要且增加复杂度。

## Risks / Trade-offs

- [风险] 无 AppBar 后返回路径可见性下降。  
  → 缓解：在页面主视图保留明确返回入口（如浮层返回按钮）并保留系统手势返回。

- [风险] 图表头部点击区域与图表触控区域可能冲突。  
  → 缓解：将头部交互区与图表绘制区垂直分层，点击热区使用最小高度与语义组件。

- [风险] 登录遮罩覆盖时仍可触发头部点击。  
  → 缓解：遮罩启用期间禁用底层交互，保持与现有行为一致。

- [权衡] 取消纵轴语义文案后，新用户学习成本略升。  
  → 收益：界面更简洁，符合“图表主视图优先”目标。

## Migration Plan

1. 更新 OpenSpec delta（新增图表头部交互能力，修改现有趋势 UI 能力）。
2. 调整 `TrendsScreen` 布局骨架并迁移交互入口。
3. 调整 `TrendGlassBarChart` 头部结构与回调参数，移除纵轴说明文案。
4. 回归验证：事件切换、日期切换、记忆恢复、登录遮罩、空态/加载态。
5. 回滚策略：恢复旧布局（AppBar + 双胶囊）并撤销图表头部交互改造。

## Open Questions

- 是否需要在无 AppBar 布局中补充固定位置返回按钮（视觉稿未最终确认）？
- 当事件目录仅 1 项时，标题点击是否仍开启选择弹层（建议保留一致行为）？
- 日期范围文案是否需要在无数据时显示额外状态标识（如“暂无可用范围”）？
