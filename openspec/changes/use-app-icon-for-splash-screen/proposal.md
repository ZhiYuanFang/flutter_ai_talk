# Proposal: use-app-icon-for-splash-screen

## Why

当前冷启动页使用的 Logo 与桌面图标存在视觉不一致，用户在启动瞬间会感知到“图标切换”。为统一品牌识别并减少跳变，需要将启动页图标切换为与桌面一致的主图标，并确保以圆形满铺方式展示。

## What Changes

- 将冷启动页（含启动遮罩与 `/splash` 占位页）的中心图标资源改为桌面主图标同源资产。
- 调整启动页图标展示规则：图标必须以圆形裁剪并尽量填满容器，不出现明显留白边框。
- 保持现有启动页背景渐变、标语文案与启动时序不变，不引入新的阻塞逻辑。
- 在实现与验证环节补充图标显示一致性检查（资源来源、圆形填充效果、多尺寸表现）。

## Capabilities

### New Capabilities

- 无

### Modified Capabilities

- `startup-splash-gradient-visual`: 修改启动页图标呈现要求，从“保持现有 splash_logo 资源与布局不变”调整为“使用桌面图标同源资产并以圆形填满展示”。

## Impact

- 影响代码：`app/lib/ui/` 下启动页/启动遮罩相关 Widget 与图标样式实现。
- 影响资源：启动页图标引用路径与可能的图标容器样式参数。
- 影响验证：需回归冷启动视觉（Android/iOS）以确认圆形填满与品牌一致性。
- 不影响：路由时序、网络请求顺序、权限与外部 API 契约。
