## 1. 同档优先的间隔中位

- [x] 1.1 同档有效间隔不少于 2 时，加权中位只用起点落在 `lastAt` 锚点桶的间隔（桶权重 1，仍乘时间衰减）；相邻与更远桶不进入
- [x] 1.2 同档不足 2 但同档加相邻不少于 2 时，用同档 1.0、相邻 0.6 再乘时间衰减做加权中位
- [x] 1.3 同档加相邻仍不足 2 时，维持全桶等权回退；仍不足则沿用种子间隔或不可预测。公式保持 `nextAt = lastAt + interval`
