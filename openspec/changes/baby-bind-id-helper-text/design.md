## Context

绑定宝宝页面当前提供“输入宝宝ID”输入框，但对“宝宝ID从哪里获取”缺少即时说明。用户尤其是首次使用时，可能不知道应向家人索取并复制该 ID，导致卡在第一步。

本次变更只涉及前端页面展示层：在输入框下方增加一行次级提示小字，不调整绑定流程、接口参数与状态管理。

## Goals / Non-Goals

**Goals:**
- 在绑定宝宝页面输入区提供简洁可见的来源说明，帮助用户快速完成绑定。
- 新增文案与当前页面视觉层级一致（小字、弱强调）。
- 不影响已有“绑定宝宝”提交逻辑与校验逻辑。

**Non-Goals:**
- 不新增交互动作（如点击跳转、复制按钮、帮助弹窗）。
- 不改后端 API、字段、路由与埋点。
- 不改创建新宝宝流程相关内容。

## Decisions

1. **文案位置：放在宝宝ID输入框下方**
   - 采用：紧贴输入行为，用户在输入前即可看到说明。
   - 不采用：放到标题或页脚，相关性弱、易被忽略。

2. **文案样式：使用小字号次级文字**
   - 采用：遵循“辅助说明”定位，不干扰主要操作。
   - 不采用：主文本样式会分散用户注意力。

3. **文案内容固定为产品给定语句**
   - 采用：与需求一致，减少歧义。
   - 不采用：自由改写可能偏离产品表达。

## Risks / Trade-offs

- [风险] 文案过长在小屏换行拥挤 → [缓解] 保持单行优先、允许自然换行，控制字号与行高。
- [风险] 弱化样式导致可见性不足 → [缓解] 使用当前主题下可读的次级文本色，而非过低透明度。
- [取舍] 仅文本提示，缺少进一步帮助入口 → [说明] 本次先满足最低引导需求，后续可再评估帮助入口。

## Migration Plan

- 无数据迁移。
- 前端发版后立即生效。
- 回滚仅需还原页面文案节点。
