## Context

`predictNextForEventKey` 现用 6 个 `timeOfDayBucket` + same→adjacent→all 阶梯投票。桶 5（18–24）把日末锚点与傍晚初段短间隔绑在一起，易中位翻簇或估出历史从未出现的钟点。产品要求不写死夜晚；发生锚点已按 `predict-interval-use-start` 用 `startTime`。本设计落地探索结论中的 **A（连续钟点亲和）+ D（环形直方图护栏）**。

## Goals / Non-Goals

**Goals:**

- 用与 `lastAt` 的钟点环形距离连续加权，取代 6 桶阶梯主路径。
- 对候选 `nextAt` 做按事件根的历史钟点直方图相对峰值校验；冷区拒绝并尝试更长/跨日候选。
- 保留：`nextAt = lastAt + interval`、≥15 分钟过滤、有效样本 ≥2、种子间隔旁路、无真 `lastAt` 不预测、`startTime` 发生锚点。

**Non-Goals:**

- 显式双峰聚类（B）、经验日末分位数产品规则（C）。
- 教科书连续 KDE（第一版用直方图近似）。
- 改 expect duration/amount、预约事件、回忆种子 lastAt 语义。
- 写死全局「20:00 后不再预测」。

## Decisions

1. **删除 6 桶作为投票主路径。**  
   不再实现 same/adjacent/all 集合切换。`timeOfDayBucket` / `bucketWeight` 可删或仅留测试遗迹，不得再驱动中位。  
   备选：桶作硬截断 — 拒绝，避免双规则。

2. **亲和权重（A）。**  
   对每条有效间隔，起点本地分钟 `m_start`，锚点 `m_last`：  
   `Δ = min(|m_start−m_last|, 1440−|…|)`（分钟）。  
   `w_tod = exp(−Δ / h)`，默认 **h = 90** 分钟；再乘既有 `recencyWeight(ageDays, halfLifeDays)`。  
   `w_tod < 0.05` 的样本丢弃。剩余 ≥2 则加权中位；否则走种子 / 不可预测。  
   备选：自适应 h — 二期再做。

3. **直方图护栏（D）。**  
   该根真发生钟点 → 一天 **48 格 × 30 分钟**（环形）；计数可对邻格 ±1 做一次平滑。  
   `score(nextAt) / max_score`；默认阈值 **α = 0.2**。  
   该根参与直方图的发生次数 **&lt; 7** 时 **跳过护栏**（不拒）。  
   备选：完整 KDE — 第一版不做。

4. **护栏失败回退。**  
   主中位得出的 `nextAt` 冷区时：在**已通过亲和截断**的样本中，取时长 ≥ 主中位的子集合（若 ≥2）再中位；若无，则仅用**跨本地自然日**的间隔（终点日期 &gt; 起点日期）再中位（若 ≥2）。新候选再跑 D；仍失败 → 该根本次不可预测（不回退到被拒的短 `nextAt`）。  
   种子旁路得出的 `nextAt` 同样过 D（样本够时）；不过则不可预测。

5. **无硬编码夜晚。**  
   冷/热只来自该根历史钟点分布；跨日用日历日边界，不用「晚上」枚举。

6. **调试。**  
   Debug 可用 `AppDebugLog` 记：有效样本数、主/回退中位分钟、直方图相对峰值、是否护栏跳过——**禁止**刷屏打全量历史。

## Risks / Trade-offs

- [带宽 h 过窄 → 常不可预测] → 默认 90min；联调可调；种子旁路兜底。  
- [同钟点双峰仍翻簇] → D 拦住冷区 nextAt；真双峰且两簇钟点都热时仍可能抖（接受，留 B 二期）。  
- [习惯突变（新开夜间）] → 半衰期偏新样本；&lt;7 次跳过 D 减少误杀。  
- [α 过严误杀合法 nextAt] → 默认 0.2 + 邻格平滑；场景验收可调。  
- [规格回归面大] → 显式废止同档/相邻 Scenario，改写亲和与护栏 Scenario。

## Migration Plan

1. 实现亲和加权 + 直方图护栏 + 回退；删桶投票路径。  
2. 用「历史最晚约 20:00、lastAt 傍晚」与「18:55/19:55 翻簇」类手工路径验收。  
3. 回滚：恢复桶投票即可；无服务端迁移。
