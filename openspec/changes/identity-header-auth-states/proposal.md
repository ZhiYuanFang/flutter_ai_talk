## Why

未登录或已登录未绑定时，喂养/预测顶栏仍展示占位宝宝昵称「未绑定宝宝ID」与虚假月龄「不满1个月啦」，与空态/门闸文案「尚未登录」不一致，误导用户以为已有宝宝身份。同时预测骨架卡片点击会直接 `push('/login')`，绕过已有软关再弹的登录/绑定门闸，体验突兀。Auth 冷态滑动引导大卡箭头易被当成快捷跳转；需点箭头弹框教滑动，养成横滑习惯（登录绑定后提示消失）。

## What Changes

- 未登录时：喂养与预测身份顶栏展示「未登录」，**不**展示月龄。
- 已登录未绑定（无可用 deviceNo）时：顶栏展示「未绑定宝宝」，**不**展示月龄（顺带整理，不再露出「未绑定宝宝ID · 不满1个月啦」）。
- 已登录且已绑定：行为不变，仍经 L1 展示原子解析真 profile。
- 预测页冷态骨架卡片点击：未登录/未绑定时 **复用** 现有登录/绑定门闸（打开），**不得**直接跳转 `/login` 或 `/settings/bind-baby`；真正跳转仍仅由门闸 CTA 触发。
- 登录/绑定门闸：**不得**在进入预测页时自动弹出；绑定与登录对称。仅点骨架卡（或明确登录/绑定 CTA）才打开；空白区 / 滑动 / 切布局 **不得**打开。
- 未登录或已登录未绑定时：隐藏「值得留意」与「接下来3小时」，改为无按钮的滑动引导大卡（左滑广场 / 右滑喂养）；箭头持续左右位移 + 心跳缩放；**保留**预测事件骨架网格。
- 点击大卡左右箭头：分别弹出玻璃引导弹框（左右文案分开），**不得**切换主壳 PageView、**不得**打开登录/绑定门闸；中间标题区不可点开弹框。
- 喂养沉浸头合成行在无月龄时仅显示昵称（无 ` · ` 月龄段）；预测顶栏隐藏月龄行。

## Capabilities

### New Capabilities

- （无）

### Modified Capabilities

- `baby-display-provider`：展示快照 MUST 感知会话与绑定态，产出未登录/未绑定专用昵称，并标明是否展示月龄（或空月龄约定）。
- `baby-display-atoms`：明确占位 profile（如 `未绑定宝宝ID`）不得原样作为身份昵称；应用身份行在无月龄时不得强拼 ` · `。
- `home-immersive-header`：未登录/未绑定身份条 MUST 按上述文案渲染且无月龄段。
- `prediction-gate-dialog`：进页不得自动弹登录/绑定；仅骨架卡（或明确 CTA）打开；空白/切布局不得打开；骨架卡不得直达登录/绑定页。
- `smart-prediction-page`：auth 冷态（未登录/未绑定）chrome 用滑动引导大卡替换留意与接下来3小时；保留骨架网格；大卡无跳转按钮；点箭头弹框教滑动（左右文案分）。

## Impact

- 代码：`baby_display_provider.dart` / `baby_age.dart`（或等价 L1/L2）、`home_immersive_header.dart`、`home_screen.dart`、`smart_prediction_screen.dart`（顶栏与 `onCardTap`、滑动引导大卡箭头弹框）。
- 规格：增量修改上述四项 capability；不改后端 API。
- 测试：不新建 `**/test/**`；手工冒烟未登录 / 已登录未绑定 / 已绑定三态顶栏，以及软关门闸后点骨架卡再弹；点左右箭头弹框且不跳页。
