## 背景与动机

首版（M1）中宝宝信息为只读 Mock、历史为纯文本摘要、趋势图未强调「今日」与坐标轴标注。照护者在实际使用中需要**纠正宝宝资料**、按统一格式**阅读与追溯事件**、对单条记录**手动改错**，并在 Web 上更快捷提交指令；趋势需对齐「看当天」与「日期轴」的阅读习惯。本变更在既有 **胖宝** 客户端上迭代这些体验与数据结构占位，仍可与 Mock/后续真实 API 对接。

## 变更内容

- **宝宝信息可编辑**：在设置中心（或专用入口）支持编辑昵称、性别、生日等字段（字段集合仍以后端为准；M 阶段可本地 Mock 持久化），保存后刷新全局主题默认值来源。
- **历史记录展示格式**：列表主文案固定为 **`{事件名}:{动作}`**（事件名、动作由服务端/Mock 字段映射；缺省时需有占位规则避免空白）。
- **历史详情与手动编辑**：主页历史行可点击，进入**二级详情页**；详情页展示该条完整信息，并允许**手动编辑**后保存（Mock 为本地/仓库更新；后续对接 PATCH/PUT）。
- **Web 回车提交**：Web 端主输入框在输入内容后按 **Enter** 键须触发与「提交」按钮相同的**提交到服务端（Mock）**流程；多行输入时需约定（如 Shift+Enter 换行、Enter 提交，或仅单行）。
- **趋势图「今日」与坐标轴**：趋势视图支持展示**当日**数据范围；图表**必须**绘制横、纵坐标轴刻度与标签；**横轴**表示**事件日期**（按点的时间维度）；纵轴为指标数值。

## 能力划分

### 新增能力（各对应 `specs/<kebab>/spec.md`）

- `baby-profile-editing`：宝宝资料展示为可编辑表单、校验、保存与回显。
- `history-format-and-detail`：历史主行 `事件名:动作` 格式、点击进入详情、详情内编辑保存。
- `web-home-enter-submit`：Web 主输入区键盘 Enter 触发提交语义。
- `trends-daily-labeled-axes`：趋势「今日」范围、带日期横轴与数值纵轴的图表要求。

### 变更的既有能力（仓库级 `openspec/specs/`）

- 无（当前仓库根下尚未归档通用 spec；本变更仅在 `changes/pangbao-m2-editing-trends` 内新增增量规格）。

## 影响范围

- **Flutter 应用**（`app/lib`）：`SettingsScreen`、宝宝模型与仓库；`HomeScreen` 历史列表与新建 `HistoryDetail` 路由；`TrendsScreen` 与 `MockTrendsRepository` 数据形状；Web 输入组件键盘行为。
- **Mock 契约**：`HistoryRecord` 或等价 DTO 需携带 `eventName`、`action`（或后端 JSON 映射）；趋势序列点须含可用于横轴的日期字段。
- **无 BREAKING** 对外 HTTP 契约声明（真实后端未定型前以 Mock 兼容为主）。
