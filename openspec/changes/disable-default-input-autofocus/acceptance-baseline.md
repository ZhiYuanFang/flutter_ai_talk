# 验收基线（任务 1.2）

## 验收范围

- 首页 `HomeScreen`
- 登录 `LoginScreen`
- 注册 `RegisterScreen`
- 设置相关输入弹窗
- 历史编辑与数值备注弹层

## 通过标准

1. 进入页面时不自动弹键盘：
   - 页面首次展示后，输入框默认不获取焦点。
2. 返回页面时不自动弹键盘：
   - 从下级页面返回后，不存在输入焦点残留。
3. 用户主动点击仍可输入：
   - 点击输入框后可正常聚焦并弹出键盘。
4. 业务流程不回归：
   - 登录/注册校验、提交按钮、`onSubmitted` 行为保持原样。
