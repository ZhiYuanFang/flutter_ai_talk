## Context

基线 `prediction-interval-sheet-thinking` 要求确认间隔后同层打字机，文末加粗说明「后续喂养节奏会**自动修改**预测时间」。实现见 `prediction_recall_interval_picker.dart`：

- 主段：`…合成推演样本，为「{event}」量身定做智能预测…`
- `_boldFooter`：`随着后续的喂养节奏，我会自动修改预测时间；…`

`predict-capability-client` 后：未 entitle 时展示轨强制种子间隔；算法展示需 basic/pro/VIP。旧文案与产品真相冲突。产品决策：**只润色**，不加试用 CTA，弱化付费开通概念。

## Goals / Non-Goals

**Goals:**

- 加粗脚注不再让用户以为「会自动变成算法预测」。
- 保留温和承诺：先按补充间隔；记录多了更贴合。
- 规格与实现字符串对齐；主段去掉「立刻上智能算法」的强暗示（轻改即可）。

**Non-Goals:**

- 不改 Sheet 相位、打字机节奏、跳过/关闭、状态行「思考完毕 · …」、upsert 时机。
- 不在思考态加「立即体验 / 开通」按钮或跳转。
- 不改双轨、settle-gate、算法就绪弹窗文案。
- 不为 AiThinkingPane 迁移本 Sheet（仍为本地 Timer 打字机）。

## Decisions

### D1：脚注语义改写（必做）

- **选择**：语义变为「先按你补充的间隔估下次；喂养记录多了，预测会更贴合实际作息」。
- **推荐落地句**（实现可微调标点，语义 MUST 对齐 spec）：  
  `接下来先按你补充的间隔来估下次时间；喂养记录多了，预测会更贴合实际作息。`
- **备选**：更短 `先按这个间隔记着；真实喂养多了，预测会越来越准。`
- **理由**：去掉「自动修改」；不提开通/付费；仍有正向预期。

### D2：主段轻改（同批）

- **选择**：保留「记下了大概每 X 一次」；将「量身定做智能预测」收为「推演下次时间」或等价，避免「智能」= 已开通算法。
- **示例**：`…正在按你的节奏推演「{event}」的下次时间…`
- **理由**：与脚注同一口径；改动面仍仅字符串。

### D3：量身定做收尾（SHOULD）

- **选择**：若收尾仍含「本地算法会…持续学习」等易读成自动切轨的句子，改为与 D1 同口径的软表述；**不得**插入付费话术。
- **理由**：入口少见，但两处叙事不一致会再误导；成本低。

### D4：不加 CTA

- **选择**：思考态不增加开通入口。
- **理由**：产品明确弱化付费开通；算法就绪另有弹窗漏斗。

## Risks / Trade-offs

- [Risk] 去掉「自动修改」后，用户以为预测永远固定 → Mitigation：保留「记录多了更贴合」；能力卡/算法就绪弹窗仍负责后续升级叙事。
- [Risk] 「更贴合」仍被读成必然切算法展示 → Mitigation：措辞强调「贴合实际作息」，不写「切换为算法预测 / 自动升级」。
- [Trade-off] 不教育「需开通」→ 可能延后转化；符合本次「弱化付费」决策。
